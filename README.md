# prisoners-dilemma-nhl-pool
Tool for calculating statistics for a hockey pool
* Python dependencies are in `dependencies.txt`.
* Populate `Picks.xlsx` following the example in `PicksTemplate.xlsx`
* Schedule regular email updates by filling in email details like in `email_settings.json.template` in `email_settings.json` 
  * if using gmail, make sure to create an app-specific password
